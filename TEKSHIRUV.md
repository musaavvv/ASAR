# Tahrir va tekshiruv

## Har bobdan keyin
- [ ] Bobning yangi fikrini bitta jumlada aytish mumkin.
- [ ] Oldingi bobni boshqa metafora bilan takrorlamaydi.
- [ ] Abstrakt fikrning aniq tayanchi bor.
- [ ] Ovoz va murojaat shakli ongli tanlangan.
- [ ] Har bir keskin hukmning chegarasi ko‘rilgan.
- [ ] O‘quvchining dardi kamsitilmagan.
- [ ] Tayyor manba jumlasi, metaforasi yoki sahnasi yashirin olinmagan.
- [ ] Diniy/faktik da’volar badiiy mulohazadan ajratilgan.
- [ ] Matn OCR xatolarini takrorlamaydi.

## Mazmuniy takror jadvali
| Fikr/obraz | Qaysi boblarda? | Keyingi ishlatishda yangi vazifa bormi? | Tahrir |
|---|---|---|---|
| | | | |
So‘zning har qanday takrorini xato deb hisoblama: motiv va ritmik takror maqsadli bo‘lishi mumkin. Mazmunsiz takrorni olib tashla. Majburiy foiz yoki “har so‘z ikki marta” kabi qoidalar yo‘q.

## Da’volar reyestri
| Da’vo | Badiiy fikr / tarix / din / psixologiya | Aniq manba | Tekshiruv holati | Nashrdagi qaror |
|---|---|---|---|---|
| | | | | |
Manba yo‘q bo‘lsa, iqtibos to‘qima. Qoralamada belgi qo‘y; tayyor nusxada olib tashla yoki tasdiqlangan manba bilan tuzat.

## Butun asar tekshiruvi
- [ ] Boshlanish bergan savol yakunda o‘zgarish yoki javob topgan.
- [ ] Boblarning tartibi ichki mantiqqa ega.
- [ ] Bir xil hissiy cho‘qqi tinmay takrorlanmagan.
- [ ] Shaxsiy tajriba universal qoida deb berilmagan.
- [ ] Manba bilan farqlanish jadvali to‘ldirilgan.
- [ ] Qolgan ochiq muammolar yashirilmagan.

## Tahrir hisobotining shakli
1. Asarning ishlayotgan jihati.
2. Eng muhim uchta muammo va aniq joyi.
3. Tuzatilgan parchalar.
4. Tekshirilmagan da’volar.
5. Manbaga ortiqcha yaqinlik xavfi.
6. Keyingi versiya uchun qarorlar.

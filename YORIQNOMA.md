# Ish yo‘riqnomasi

## 1. Asar pasporti
Yozishdan oldin quyidagilarni to‘ldir:
| Maydon | Qiymat |
|---|---|
| Bir jumladagi g‘oya | |
| O‘quvchi va uning asosiy savoli | |
| Shakl: esse / lirik nasr / hikoya / roman | |
| Mavzu va muallifning mustaqil pozitsiyasi | |
| Hissiy boshlanish va yakundagi o‘zgarish | |
| Hikoyachi: men / sen / uchinchi shaxs | |
| Diniy mazmun darajasi | |
| Hajm va boblar soni | |
| Ko‘chirilmasligi kerak bo‘lgan manba unsurlari | |

Noma’lum maydonni yashirin taxmin bilan to‘ldirma: taklif deb belgilab, tasdiqqa chiqar. Har safar barcha savollarni qayta so‘rama; foydalanuvchi bergan ma’lumotni ishlat.

## 2. Uch konsepsiya
Bir g‘oyaga uch xil kompozitsiya taklif qil. Faqat nomlari emas, boshlanish vaziyati, yetakchi savol, ovoz va yakun mantig‘i farqlansin. Eng mustaqil variantni izohla.

## 3. Reja
TUZILMA.md asosida boblar jadvalini tuz. Har bob yangi savol, dalil yoki hissiy siljish olib kelsin. Bir fikrni bezab takrorlashni rivojlanish deb hisoblama.

## 4. Sinov matni
Avval bitta to‘liq bob yoz. Ovozi, nasihat darajasi, obrazlarning tabiiyligi va manbadan farqi tekshirilsin. Tasdiqlangach, qolgan boblarni shu loyiha pasportiga muvofiq yoz.

## 5. Ish xotirasi
Har bobdan keyin qisqa qayd saqla: yangi fikr; ishlatilgan obraz; qaytuvchi motiv; ochiq savol; keyingi bobga ko‘prik. Hikoyada qahramonlar va xronologiyani ham yangila.

## 6. Tahrir
Avval mazmun va kompozitsiya; keyin original ifoda; so‘ng fakt va diniy iqtibos; oxirida imlo. Chiroyli jumla mantiqsiz fikrni oqlamaydi.

## 7. Manba intizomi
Kitobdagi muallif mulohazasi ilmiy dalil yoki diniy hukm emas. Oyat uchun sura/oyat va tarjima manbasi, hadis uchun to‘plam/raqam hamda ishonchlilik tekshiruvi talab qil. Tekshirilmagan joyni [MANBA KERAK] deb belgilab, nashrga tayyor matndan chiqar. To‘qima hikmatni mashhur shaxsga nisbat berma.

## Chegara
Eski oilaviy drama tizimidagi 33 foiz bog‘lovchi, majburiy xiyonat/ajralish so‘zlari yoki Dzen cheklovlari bu loyihaga ko‘chirilmaydi. Yangi qoida dalil yoki aniq tahririy maqsadga ega bo‘lsin.
